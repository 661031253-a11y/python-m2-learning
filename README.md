## Google Sheets ต้องสร้างตอนนี้ไหม?
**ยังไม่จำเป็นค่ะ** เว็บไซต์เปิดและเก็บคะแนนไว้ในเบราว์เซอร์ได้โดยไม่ต้องสร้าง Google Sheets แต่ถ้าต้องการให้ครูดูข้อมูลนักเรียนที่ใช้จากหลายเครื่อง ให้สร้าง Google Sheets และตั้งค่าเชื่อมต่อก่อนใช้งานจริง

### วิธีเชื่อม Google Sheets (ทำภายหลังได้)
1. สร้าง Google Sheets ใหม่ในบัญชี Google ของคุณ ตั้งชื่อเช่น `ผลการเรียน Python ม.2`
2. ในชีต เลือก **ส่วนขยาย (Extensions) → Apps Script**
3. เปิดไฟล์ `Code.gs` ที่อยู่ใน ZIP แล้วคัดลอกโค้ดไปวางใน Apps Script จากนั้นบันทึก
4. เลือก **Deploy → New deployment → Web app**
5. ตั้งค่า Execute as: **Me** และเลือกสิทธิ์เข้าถึงที่เหมาะสมกับการใช้งานในโรงเรียน จากนั้น Deploy และอนุญาตสิทธิ์
6. คัดลอก URL ของ Web app ที่ลงท้ายด้วย `/exec`
7. เปิดไฟล์ `config.js` แล้วใส่ URL ดังนี้: `window.GAS_URL = 'วาง_URL_ที่ได้';` จากนั้นบันทึก
8. เปิดเว็บใหม่และทดลองส่งข้อมูลหนึ่งครั้ง แล้วตรวจสอบว่ามีแถวข้อมูลเพิ่มในชีต

**ข้อควรระวัง:** หากตั้งค่า Web app ให้ทุกคนเข้าถึงได้ ข้อมูลชื่อและคะแนนนักเรียนจะถูกส่งไปยังบริการภายนอก ควรปฏิบัติตามนโยบายโรงเรียนและขออนุญาตผู้เกี่ยวข้องก่อนใช้ข้อมูลจริง โหมดครูในเว็บต้นแบบนี้ยังไม่ใช่ระบบล็อกอินที่ปลอดภัย

## สนามทดลอง Python (อัปเดต)
สนามทดลองใช้ Pyodide เพื่อรัน Python จริงในเบราว์เซอร์ โดยต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดระบบในครั้งแรก รองรับตัวแปร การคำนวณ เงื่อนไข การวนซ้ำ และฟังก์ชันตามที่ Pyodide รองรับ มีปุ่มคัดลอกโค้ดทั้งในตัวอย่างและสนามทดลอง ปุ่มคัดลอกต้องใช้ผ่าน HTTPS หรือ localhost ในเบราว์เซอร์ที่รองรับ Clipboard API (มีทางเลือกสำรองสำหรับบางเบราว์เซอร์)

## การอัปเดตระบบล่าสุด
- ระบบจะไม่ล้าง `pyRecords` อัตโนมัติเมื่อเปิดเว็บไซต์เวอร์ชันใหม่ ข้อมูลเดิมในเบราว์เซอร์จึงไม่ถูกลบจากการอัปเดตโค้ด
- คะแนนก่อนเรียน/หลังเรียนล่าสุดจะถูกอ่านกลับจากข้อมูลที่บันทึกไว้ตามชื่อ ชั้น และเลขที่ของนักเรียน
- สนามทดลองมีความก้าวหน้ากล่องสุ่ม 10 โจทย์ แยกตามนักเรียน และบันทึกโจทย์ที่ผ่านแล้วในเบราว์เซอร์
- เพิ่มปุ่ม “ตรวจคำตอบ” สำหรับโจทย์สุ่ม โดยตรวจโครงสร้างที่จำเป็นและการทำงานเบื้องต้น ไม่ใช่การรับประกันความถูกต้องของทุกวิธีเขียนโค้ด
- หน้าสำหรับครูแสดงจำนวนโจทย์สนามทดลองที่ผ่านแล้ว และดาวน์โหลด CSV ได้ รวมทั้งค้นหาและกรองชั้นเรียน
- การเชื่อม Google Sheets ใช้การส่งข้อมูลแบบ `text/plain` เพื่อลดปัญหา preflight ของเบราว์เซอร์ และยังต้องใส่ URL Web App ใน `config.js` ด้วยตนเอง

## ตรวจสอบก่อนใช้จริง
1. เปิดเว็บผ่าน Chrome/Edge และทดลองเข้าสู่ระบบด้วยนักเรียนตัวอย่าง 1 คน
2. ทำก่อนเรียน 10 ข้อ แล้วออกจากเว็บและเข้าสู่ระบบด้วยข้อมูลเดิม ตรวจว่าคะแนนยังแสดงอยู่
3. ทดลองสุ่มโจทย์ให้ครบ 10 รอบ ตรวจว่าไม่ซ้ำกันภายในรอบ และแสดงความก้าวหน้า 1/10 ถึง 10/10
4. ทดลองเติมโค้ดตั้งต้น กดรัน และกด “ตรวจคำตอบ” ทั้งกรณีถูกและผิด
5. ทดลองทำหลังเรียน 15 ข้อ ตรวจว่าคะแนนเต็มเป็น 15 และผลต่างร้อยละแสดงถูกต้อง
6. เข้าหน้าสำหรับครู ตรวจตาราง ค้นหา กรองชั้นเรียน และดาวน์โหลด CSV
7. หากใช้ Google Sheets ให้ตั้งค่า Web App ก่อน แล้วทดลองส่งข้อมูลจริง 1–2 รายการและตรวจแถวในชีต
